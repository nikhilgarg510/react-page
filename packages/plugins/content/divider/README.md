# @react-page/plugins-divider

A divider plugin for React Page Editor that adds horizontal dividers/separators between content sections.

## Installation

```bash
npm install @react-page/plugins-divider
```

## Usage

```jsx
import divider from '@react-page/plugins-divider';
import '@react-page/plugins-divider/lib/index.css';

const cellPlugins = [divider];

<Editor cellPlugins={cellPlugins} />
```

## Features

- Simple horizontal divider
- Customizable styling
- Clean visual separation between content sections
